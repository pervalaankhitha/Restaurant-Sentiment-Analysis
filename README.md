# Restaurant Sentiment Analysis

## Project Overview
Restaurant Sentiment Analysis is a Machine Learning project that analyzes restaurant reviews and classifies them as positive or negative sentiments.

## Objective
The main objective of this project is to understand customer opinions and identify whether restaurant reviews express positive or negative feedback.

## Technologies Used
- Python
- Machine Learning
- Natural Language Processing (NLP)
- Scikit-learn
- Pandas
- Flask

## Project Files
- `app.py` – Main application file
- `requirements.txt` – Required Python libraries
- `sentiment_model.pkl` – Trained machine learning model

## How to Run the Project

1. Clone the repository.
2. Install the required libraries.
3. Run the application.

```bash
pip install -r requirements.txt
python app.py
```

## Project Outcome
The application predicts sentiment from restaurant reviews and helps understand customer feedback.
